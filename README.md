# 🌾 AgriAI — Smart Agriculture Intelligence System

> **Advanced AI-Powered Precision Agriculture Platform Designed for Indian Farmers**

AgriAI is an intelligent, accessible web application engineered to optimize farming decisions, detect crop diseases, provide micro-climate weather advisories, deliver real-time mandi price intelligence, and formulate cost-effective agronomic recommendations for Indian farmers.

---

## 🌟 Key Features

- 📸 **Crop Disease Detection**: Instant symptom and leaf pattern identification with step-by-step low-cost remedies.
- 🌦️ **Micro-Climate Weather Advisor**: 5-day agro-meteorological forecasting with spray, sowing, and harvesting window alerts.
- 📈 **Mandi Price & Market Analyst**: Real-time wholesale APMC mandi price tracking and strategic selling verdict.
- 🌱 **Fertilizer & Soil Planner**: Balanced N-P-K dosage calculators and bio-fertilizer schedules.
- 🔄 **End-to-End Smart Decision Engine**: Unified 5-step pipeline that synthesizes disease diagnosis, live weather, and mandi trends into a 48-hour tactical farming plan.
- 🎙️ **Kisan Vaani (किसान वाणी / কৃষক বাণী) — Multilingual Voice Assistant**:
  - **13 Languages & Regional Dialects Supported**:
    - **North East India**: Assamese (অসমীয়া), Bodo (बड़ो), Manipuri (মৈতৈলোন্), Khasi (Ka Ktien Khasi), Mizo (Mizo ṭawng), Nepali (नेपाली), Nagamese.
    - **Uttar Pradesh & Bihar**: Bhojpuri (भोजपुरी), Maithili (मैथिली), Magahi (मगही), Awadhi (अवधी).
    - **National**: Hindi (हिन्दी) & English.
  - **100% Autonomous & Key-Free**: Native browser Web Speech API (`SpeechRecognition` & `SpeechSynthesis`).
  - **Animated Multi-Frequency Equalizer**: 12-bar real-time soundwave visualizer.
  - **Spoken Report Reader**: One-click hands-free reading of complete agricultural advisories in vernacular dialects.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/arjitjaiswal08-art/Agri-Intelligence-System.git

# Navigate into the project
cd Agri-Intelligence-System

# Open index.html in your browser
open index.html
```

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom Design System, Glassmorphism, Dark Mode)
- **Voice Intelligence**: W3C Web Speech API (`SpeechRecognition`, `SpeechSynthesis`)
- **Visuals**: Dynamic Canvas Particle System, CSS Soundwave Equalizer, SVG Plant Disease Models
- **Zero Dependencies**: 100% autonomous client-side execution, no external frameworks or build steps required.
